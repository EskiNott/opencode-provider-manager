# Contributing

Contributions are welcome.

1. Fork the repository and create a focused branch.
2. Do not commit provider credentials, private endpoints, generated OpenCode configuration, caches, or backups.
3. Run `npm test` before opening a pull request.
4. Describe which provider response format or effort rule the change covers, and include a sanitized fixture when possible.

Model capability rules should be conservative. Unknown models should remain usable without inventing unsupported reasoning-effort values.
